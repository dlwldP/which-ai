# 사용성 테스트 가이드 (비개발자 3명)

기획서 13장 Phase 5 완료 조건: **비개발자 3명에게 써보게 하고 피드백 반영.**
J가 참가자를 만나서 진행하고, 결과를 아래 기록 양식에 적어요. 결과를 Claude에게 주면 고칠 것을 정리해 제안해요.

## 준비

| 항목 | 내용 |
| --- | --- |
| 참가자 | 비개발자 3명. 가능하면 다른 유형으로: 직장인 1, 대학생 1, 부모님 세대 1 |
| 기기 | 참가자 본인 휴대폰 (가장 많이 쓸 환경). 한 명은 컴퓨터로 해도 좋아요 |
| 주소 | 실제 데이터를 넣은 뒤라면 https://dlwldp.github.io/which-ai/ <br>아직이라면 https://dlwldp.github.io/which-ai/?demo#/ (맨 위 "예시 데이터예요" 띠가 보인다고 미리 말해 주기) |
| 시간 | 1명당 15~20분 |
| 기록 | 화면 녹화나 메모. 녹화하면 시작 전에 동의 받기 |

> 실제 툴 데이터를 넣기 전에 테스트하면 화면 흐름(고르기 → 결과 → 조건 칩으로 다시 고르기)은 확인할 수 있지만, 툴 이름·정보가 가짜라서 "믿을 만한가?"는 확인하기 어려워요. 가능하면 데이터를 넣은 뒤에 하는 걸 권해요.

## 진행 대본

1. **시작 (1분)**
   > "새로 만든 사이트를 써보면서 불편한 점을 찾는 거예요. 사이트를 시험하는 거지 ○○님을 시험하는 게 아니에요. 생각나는 걸 소리 내서 말해 주시면 큰 도움이 돼요. 제가 중간에 도와드리지 않을 수도 있어요."
2. **첫인상 (1분):** 홈 화면을 보여주고 묻기
   > "이 사이트가 뭐 하는 곳 같으세요?"
3. **과제 4개 (각 2~4분):** 아래 과제를 하나씩 읽어 주고, 참가자가 혼자 해보게 해요. 막혀도 바로 도와주지 말고 1분 정도 기다려요.
4. **마무리 질문 (3분):** 아래 질문

## 과제 (기획서 5장 시나리오)

| # | 읽어 줄 문장 | 성공 기준 |
| --- | --- | --- |
| 1 | "회사 회의 녹음을 글로 정리하고 싶어요. 회사 자료라서 보안이 걱정돼요. 쓸 만한 걸 찾아보세요." | "회의·강의 녹음 정리" 선택 → 결과 위 "회사 자료라 보안 중요" 칩을 누름 → 카드 배지나 "자세히 보기"에서 학습 정책을 보고 하나를 고름 |
| 2 | "수업 발표 PPT를 만들어야 하는데 돈은 안 쓰고 싶어요. 뭘 쓰면 될지 찾아보세요." | "발표자료 만들기" → "무료만" 칩 → "자세히 보기"에서 무료 한도를 확인함 |
| 3 | "찾은 툴 하나를 골라서, 처음에 어떻게 시작하는지 알아보세요." | 카드의 "자세히 보기"나 상세 화면에서 "이렇게 시작해요" 3단계를 찾음 |
| 4 | "AI로 뭘 할 수 있는지 잘 모르겠어요. 사이트에서 뭐부터 해보면 좋을지 찾아보세요." | "뭘 해야 할지 모르겠어요" 바로가기를 찾음 |

**관찰할 것:** 어디서 멈칫하는지, 잘못 누르는 곳, 읽지 않고 지나치는 곳, 혼잣말, 밑줄 친 용어나 ⓘ를 누르는지, "자세히 보기"를 열어보는지, 조건 칩을 찾는지, 휴대폰에서 카드를 옆으로 넘기는지.

## 마무리 질문

1. 가장 쉬웠던 부분과 가장 헷갈렸던 부분은 어디였나요?
2. 추천 이유(카드 위 강조 문장과 배지)를 보고 이 툴을 믿을 수 있겠다는 느낌이 들었나요? 왜요?
3. 모르는 말이 있었나요? (예: 학습 정책, 무료 한도, 프롬프트)
4. 실제로 이 중 하나를 써보실 것 같나요? 써본다면 무엇을, 아니라면 왜요?
5. 친구에게 이 사이트를 설명한다면 뭐라고 하시겠어요?
